## solution-databases-WORKING.md

Add a section in the existing style (H3, database name, key tables, key design decisions):

- **Database:** `questionsets-db` (Azure SQL; "when in doubt, use Azure SQL").
- **Key tables:** `question_sets`, `question_set_versions` (payload JSON, immutable once published), `option_lists`, `option_list_options`, `prefill_sources`, `question_set_responses`, `response_answers`, `response_attachments`, `response_halts`.
- **Key design decisions:** derived version state; unique active response per context and question set; answers never logged.

- Note the existing inconsistency (Organizations "Cosmos" in `solution-tech-standards.md` versus Azure SQL in the databases doc) rather than cite either as authoritative for Organizations.
