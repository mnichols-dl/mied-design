# Credentialing - Permissions Catalog

**Domain:** Credentialing
**Version:** 1.0

This document defines all atomic permissions for the Credentialing domain.

---

## Permissions

| Category                | Permission ID                                 | Description                                                      | Applicable Scopes                             | Notes                                                                                              |
| ----------------------- | --------------------------------------------- | ---------------------------------------------------------------- | --------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Credential Definitions  | `credentialing.credential-definition.view`    | View credential type definitions and requirements                | System-wide                                   | Read-only access to credential catalogs                                                            |
| Credential Definitions  | `credentialing.credential-definition.manage`  | Create, edit, or deprecate credential definitions                | System-wide                                   | System Admin only                                                                                  |
| Endorsement Definitions | `credentialing.endorsement-definition.view`   | View endorsement types and requirements                          | System-wide                                   | Read-only access to endorsement catalog                                                            |
| Endorsement Definitions | `credentialing.endorsement-definition.manage` | Create, edit, or deactivate endorsement definitions              | System-wide                                   | System Admin only                                                                                  |
| Application Submission  | `credentialing.application.submit`            | Submit credential applications (new, renewal, endorsement)       | Self-only                                     | All authenticated educators                                                                        |
| Application Review      | `credentialing.application.view`              | View credential applications                                     | System-wide, Entity, District, ISD            | Scope determines visibility                                                                        |
| Application Processing  | `credentialing.application.approve`           | Approve applications flagged for review                          | System-wide, Assigned-only                    | Assigned-only scope limits visibility to applications assigned to the individual processor — see `credentialing-domain.md` Open Question #34 |
| Application Processing  | `credentialing.application.deny`              | Deny applications flagged for review                              | System-wide, Assigned-only                    | Assigned-only scope limits visibility to applications assigned to the individual processor — see `credentialing-domain.md` Open Question #34 |
| Application Processing  | `credentialing.application.place-hold`        | Place application on hold pending additional review              | System-wide, Assigned-only                    | Assigned-only scope limits visibility to applications assigned to the individual processor — see `credentialing-domain.md` Open Question #34 |
| Manual Override         | `credentialing.application.manual-submit`     | Manually enter applications on behalf of educators               | System-wide, Entity, District, ISD            | For bulk data entry, historical corrections, or single-application submission on behalf of an educator who cannot access the system (application still passes through standard validations — not a bypass; see `credentialing-sequences.md`'s "Submit New Certificate Application") |
| Manual Override         | `credentialing.application.bypass-validation` | Override business rule validations during processing             | System-wide                                   | System Admin only, fully audited                                                                   |
| Application Management  | `credentialing.application.delete`            | Delete own application if still in "Submitted" status            | Self-only                                     | Limited to pre-processing stage                                                                    |
| Credential Issuance     | `credentialing.credential.issue`              | Manually issue a credential record, correcting for an administrative error (e.g. an approved application that failed to generate its credential) | System-wide, Entity, District, ISD            | For corrective issuance only — "emergency" issuance framing removed, no FDD evidence found for a workflow-bypassing emergency path; **no sequence or API endpoint currently models this permission**, draft one if the corrective use case is confirmed as real |
| Credential Issuance     | `credentialing.permit.issue`                  | Issue temporary permits to educators                             | System-wide, Entity, District, ISD            | Scoped by organizational hierarchy                                                                 |
| Credential Management   | `credentialing.credential.view`               | View issued credentials                                          | System-wide, Entity, District, ISD, Self-only | Educators see their own; admins see by scope                                                       |
| Credential Management   | `credentialing.credential.print`              | Print official credential certificates                           | Self-only, System-wide                        | Educators print their own; admins can print any                                                    |
| Credential Management   | `credentialing.credential.suspend`            | Suspend active credentials                                       | System-wide                                   | System Admin only                                                                                  |
| Credential Management   | `credentialing.credential.revoke`             | Permanently revoke credentials                                   | System-wide                                   | System Admin only                                                                                  |
| Credential Management   | `credentialing.credential.reinstate`          | Reinstate suspended credentials                                  | System-wide                                   | System Admin only                                                                                  |
| Endorsement Management  | `credentialing.endorsement.view`              | View endorsements on credentials                                 | Self-only, System-wide                        | Educators see their own; admins see all                                                            |
| Endorsement Management  | `credentialing.endorsement.add`               | Add endorsements to existing certificates                        | Self-only (via application)                   | Educators submit applications; auto or manual approval                                             |
| Endorsement Management  | `credentialing.endorsement.nullify`           | Remove endorsements from certificates                            | System-wide                                   | System Admin only                                                                                  |
| Reporting               | `credentialing.reports.view`                  | View application status and volume reports                       | System-wide, Entity, District, ISD            | Scope-aware reporting                                                                              |
| Audit                   | `credentialing.audit.view`                    | View credential and application audit logs                       | System-wide, Entity, District, ISD            | Scope-aware audit visibility                                                                       |
| Assessment Results      | `credentialing.assessment-result.view`        | View subject area assessment results for educators               | System-wide, Self-only                        | Educators see their own; processors see all                                                        |
| Guidance Documents      | `credentialing.guidance.view`                 | View credential issuance guidance documentation                  | System-wide                                   | All authenticated users                                                                            |
| Guidance Documents      | `credentialing.guidance.manage`               | Upload and manage guidance documents                             | System-wide                                   | System Admin only                                                                                  |
| Configuration           | `credentialing.definition.compare-versions`   | Compare different versions of credential/endorsement definitions | System-wide                                   | For auditing and compliance review                                                                 |
| Assessment Definitions  | `credentialing.assessment-definition.view`    | View assessment type definitions and version history             | System-wide                                   | Read-only access to assessment catalog                                                             |
| Assessment Definitions  | `credentialing.assessment-definition.manage`  | Create, edit, or retire assessment definitions                   | System-wide                                   | System Admin only; creates versioned changes                                                       |
| Assessment Results      | `credentialing.assessment-result.import`      | Upload and import assessment result files from providers         | System-wide                                   | Admin uploads CSV/XLSX from Pearson, ETS, etc.; system parses and creates AssessmentResult records |
