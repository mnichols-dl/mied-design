# Professional Practice Review - Permissions Catalog

This document defines all atomic permissions for the Professional Practice Review domain.

---

## Permissions

| Category               | Permission ID                      | Description                                                                 | Applicable Scopes                         | Notes                                                                              |
| ---------------------- | ---------------------------------- | --------------------------------------------------------------------------- | ----------------------------------------- | ---------------------------------------------------------------------------------- |
| Self-Disclosure        | `profpractice.disclosure.submit`   | Submit self-disclosure of criminal conviction or disciplinary action        | Self-only                                 | All authenticated educators                                                        |
| Self-Disclosure        | `profpractice.disclosure.view`     | View disclosure history and status                                          | Self-only, System-wide, Worklist-specific | Educators see own; reviewers see assigned/all                                      |
| PPR Response           | `profpractice.response.submit`     | Submit annual Professional Practice Review response                         | Self-only                                 | All authenticated educators; required annually                                     |
| PPR Response           | `profpractice.response.view`       | View PPR response history                                                   | Self-only, System-wide                    | Educators see own; admins see all                                                  |
| Disclosure Review      | `profpractice.disclosure.search`   | Search and filter disclosures across worklists                              | System-wide, Worklist-specific            | PPR Reviewer role; includes advanced filters                                       |
| Disclosure Review      | `profpractice.disclosure.edit`     | Edit disclosure details during active review                                | System-wide, Worklist-specific            | Can modify date, type, description, attachments while status is "Under PPR Review" |
| Disclosure Processing  | `profpractice.status.update`       | Change disclosure status through workflow                                   | System-wide, Worklist-specific            | PPR Reviewer role; enforce valid status transitions                                |
| Disclosure Processing  | `profpractice.remarks.add`         | Add comments to disclosures (internal or external)                          | System-wide, Worklist-specific            | PPR Reviewer role; remark type determined by API parameter                         |
| Disclosure Processing  | `profpractice.disclosure.finalize` | Mark disclosure as reviewed and lock for editing                            | System-wide, Worklist-specific            | Transitions to "Reviewed-*" status; prevents further edits                         |
| Disclosure Processing  | `profpractice.disclosure.revert`   | Revert finalized disclosure back to "Under PPR Review"                      | System-wide                               | PPR Admin role only; allows corrections after finalization                         |
| Disclosure Deletion    | `profpractice.disclosure.delete`   | Remove disclosure from view but retain in audit (soft delete)               | System-wide                               | PPR Admin role only; educator cannot delete own disclosures                        |
| Account Markers        | `profpractice.markers.view`        | View account-level markers (Mandatory Hold, Enhanced Monitoring, Re-Review) | System-wide, Entity, District, ISD        | PPR Reviewer can view; visibility by scope                                         |
| Account Markers        | `profpractice.markers.manage`      | Set or clear any account marker type                                        | System-wide                               | PPR Admin or Credentialing Admin role; requires justification; fully audited       |
| Assessments            | `profpractice.clearance.view`      | View PPR clearance assessment for credential applications                   | System-wide, Entity, District, ISD        | Credentialing staff check clearance before approval                                |
| Assessments            | `profpractice.eligibility.view`    | View roster eligibility assessment for employment                           | System-wide, Entity, District, ISD        | District HR checks eligibility before roster addition                              |
| External Integration   | `profpractice.rapback.view`        | View Rap Back notification metadata                                         | System-wide                               | PPR Reviewer role; see notification date, TCN, judicial marker                     |
| External Integration   | `profpractice.rapsheet.retrieve`   | Initiate on-demand rap sheet retrieval via CHRISS SOAP call                 | System-wide                               | PPR Reviewer role; display-only, never stored                                      |
| External Integration   | `profpractice.nasdtec.view`        | View NASDTEC disciplinary records matched to educators                      | System-wide                               | PPR Reviewer role; includes clearinghouse URL                                      |
| External Integration   | `profpractice.nasdtec.access`      | Access external NASDTEC clearinghouse site for full details                 | System-wide                               | PPR Reviewer role; opens clearinghouse URL in new tab                              |
| Audit                  | `profpractice.actions.log`         | Document external activities (phone calls, emails, manual reviews)          | System-wide, Worklist-specific            | PPR Reviewer role; creates audit trail for offline actions                         |
| Audit                  | `profpractice.audit.view`          | View disclosure and marker audit logs                                       | System-wide, Entity, District, ISD        | Scope-aware audit visibility                                                       |
| Worklist Management    | `profpractice.worklist.view`       | View assigned PPR worklists and queued disclosures                          | Worklist-specific                         | PPR Reviewer assigned to specific worklists                                        |
| Worklist Management    | `profpractice.worklist.configure`  | Create, edit, or pause PPR worklists and routing rules                      | System-wide                               | PPR Admin role only                                                                |
| Worklist Management    | `profpractice.worklist.assign`     | Add or remove reviewers from worklists                                      | System-wide                               | PPR Admin role only                                                                |
| Question Configuration | `profpractice.questions.view`      | View PPR question configurations and branching logic                        | System-wide                               | Read-only access to form definitions                                               |
| Question Configuration | `profpractice.questions.manage`    | Create, edit, or activate PPR question configurations                       | System-wide                               | System Admin only; creates versioned changes                                       |
| Documents              | `profpractice.attachments.view`    | View supporting documents attached to disclosures                           | System-wide, Worklist-specific, Self-only | Educators see own; reviewers see assigned disclosures                              |
| Documents              | `profpractice.attachments.upload`  | Upload supporting documents to disclosure                                   | Self-only                                 | Educators upload to their own disclosures during submission                        |
| Documents              | `profpractice.attachments.delete`  | Remove document from view but retain in audit (soft delete)                 | System-wide                               | PPR Reviewer role; requires justification                                          |
| Reporting              | `profpractice.report.view`         | View and export all PPR reports, metrics, and analytics                     | System-wide, Entity, District, ISD        | Scope-aware; includes export                                                       |
| District Notifications | `profpractice.notifications.view`  | View PPR-related notifications for district users                           | District, ISD                             | District HR sees alerts for educators they're hiring/employing                     |
